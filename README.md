## Personal Portfolio Website

**Technologies:** MongoDB, Express.js, React.js, Node.js, JavaScript, Tailwind CSS, Vercel

**Project Overview**

Developed and deployed a responsive personal portfolio website using the MERN stack to showcase professional skills, technical projects, and career experience. Designed an interactive user interface to provide recruiters and visitors with an overview of my development capabilities.

**Key Features**
- Responsive UI for desktop, tablet, and mobile devices.
- Dedicated sections for professional introduction, technical skills, projects, and contact information.
- Project showcase with descriptions and links to live applications and source code.
- Contact section to help recruiters and potential clients connect.
- Deployed on Vercel for online accessibility.

**Project Link:** https://profile-iota-sand-69.vercel.app/
